## Giới thiệu

**EduHub Web** là cổng thông tin câu lạc bộ và sự kiện sinh viên Trường Đại học Đồng Tháp.
Website được xây dựng dần qua từng chương của môn học: bắt đầu từ HTML ngữ nghĩa, sau đó tạo kiểu bằng CSS hiện đại, chạy tốt trên điện thoại, máy tính bảng và máy tính.

Website gồm 4 trang: **Trang chủ**, **Lịch sự kiện**, **Chi tiết sự kiện** và **Đăng ký thành viên**.

## Chạy trên máy

1. Clone repo về máy:
```bash
   git clone https://github.com/karie-212/IN452902-LapTrinhFrontEnd.git
```
2. Mở thư mục vừa clone bằng VS Code (**File → Open Folder**).
3. Cài extension **Live Server** (tác giả Ritwick Dey) trong tab Extensions.
4. Vào thư mục chương muốn xem (ví dụ `chuong-02`), chuột phải vào `index.html` và chọn **Open with Live Server**.
5. Trình duyệt tự mở trang. Mỗi lần lưu file, trang sẽ tự tải lại.

> Lưu ý: không mở trang bằng cách nhấp đúp file `.html`, vì một số đường dẫn có thể không hoạt động đúng.
